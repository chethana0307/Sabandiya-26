# Sabandiya '26 🌸

**Where hearts connect, where memories begin.**

Two interactive web invitations for Sabandiya '26 at CINEC Campus, created for the **BBM in Accounting** and **BBM in Banking and Finance** degree programmes. The student version welcomes the new batch, while the lecturer version extends a formal invitation to our lecturers.

## Live invitations

| Audience | Open the invitation |
| --- | --- |
| Lecturers | [Lecturer invitation](https://sabandiya-lecturers.netlify.app/) |
| Students | [Student invitation](https://sabandiya-sudent.netlify.app/) |

## Features

- Tap-to-open envelope with a decorative lotus seal.
- Matching visual design with audience-specific messages.
- Responsive layouts for mobile and desktop screens.
- Event date, time, venue, and programme information.
- Embedded images and inline CSS and JavaScript in each HTML file.
- Keyboard support for opening the invitation.

## View the invitations

Use the Netlify links above to open either invitation, then tap or click the lotus seal.

To view a downloaded invitation locally, open its HTML file in a web browser. No package installation, build step, API keys, or backend is required. Google Fonts needs an internet connection; fallback fonts are used when those fonts cannot load.

## Customize

Edit the relevant invitation HTML file in a text editor. You can update the invitation wording, programme names, event details, colours, and typography. Each invitation is independent, so apply shared changes to both files.

When changing the event date, update both the details section and the closing message.

## Deployment

Both invitations are hosted on **Netlify** as separate static websites. Each version can be deployed with its invitation file named `index.html`. No build command is required.
